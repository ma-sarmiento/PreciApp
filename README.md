# Preciapp
PreciApp es una aplicación desarrollada como parte de la clase de Computación Móvil. Su objetivo es permitir a los usuarios escanear productos, comparar precios en diferentes tiendas y optimizar su ruta de compras.

## Funcionalidades
- Escaneo de productos mediante código de barras.
- Comparación de precios entre diferentes tiendas.
- Definición de un presupuesto para las compras.
- Sugerencia de una ruta eficiente para realizar las compras.

## Tecnologías
- Desarrollada en Kotlin para Android.
- Uso de Firebase para almacenamiento.
- Google Maps para la funcionalidad de rutas.


## Cómo usar
1. Clona el repositorio en tu máquina.
2. Crea una base de datos en Firebase y configura la autenticación y permisos básicos.
3. Descarga el archivo google-services.json de tu proyecto en Firebase y colócalo en el directorio app del proyecto.
4. Abre el proyecto en Android Studio.
5. Compila y ejecuta la aplicación en un emulador o dispositivo físico.

Al ejecutar el código, la base de datos se poblará con información JSON. Sin la configuración de Firebase propia, la aplicación no podrá funcionar correctamente.
